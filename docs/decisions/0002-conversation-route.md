# ADR 0002: диалоговый маршрут через Conversation Service

Статус: принято.

## Контекст

Прямой вызов Agent Runtime не хранит диалог и не создаёт действие. Conversation Service уже владеет этой
оркестрацией согласно общему ADR-0013.

## Решение

- добавить `POST /api/v1/conversations/messages`;
- передавать запрос и исходный Bearer token в Conversation Service;
- возвращать вопрос или карточку без изменения данных;
- временно сохранить `POST /api/v1/messages` и прямой Agent Client для совместимости;
- удалить старый маршрут только в следующей major-версии контракта.

## Последствия

Новые каналы получают единое состояние диалога и общий виджет. Во время миграции Gateway имеет две
исходящие зависимости. После перехода клиентов Agent Client и настройки коннекторов будут удалены.
