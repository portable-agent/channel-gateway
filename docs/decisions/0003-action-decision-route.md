# ADR 0003: решение виджета проходит через Channel Gateway

Статус: принято.

## Контекст

Widget SDK создаёт безопасную команду с `actionId`, `payloadHash` и решением, но не выполняет HTTP.
Если каждый адаптер знает адрес Action Service, внутреннее устройство платформы протечёт в Telegram,
Web и VK, а обработка ошибок начнёт различаться.

## Решение

- добавить `POST /api/v1/actions/{actionId}/decisions` в публичную границу Gateway;
- проверить JWT и форму команды до вызова зависимости;
- передать исходный Bearer token и команду в Action Service без изменения;
- вернуть `202`, безопасный `409` или `502` без внутренних данных зависимости;
- не переносить policy, approval или состояние действия в Gateway.

## Последствия

Адаптеры каналов работают с одним backend-адресом для сообщений и решений. Action Service остаётся
источником состояния и единственным местом проверки `payloadHash`.
