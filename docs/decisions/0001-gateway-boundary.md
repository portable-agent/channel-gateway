# ADR 0001: граница первого инкремента

Статус: принято.

## Контекст

Каналы имеют разные API, но продукту нужен один вход. Conversation Service, голос и Widget SDK ещё не
реализованы. Нельзя выдавать их поведение за готовое.

## Решение

- Gateway принимает только нормализованный текст и настройки представления.
- Identity берётся только из проверенного JWT.
- Доступные коннекторы приходят из серверной конфигурации.
- В первом инкременте Gateway синхронно вызывает Agent Runtime.
- Ответ переиспользует `ProposalResponse` из общего contract bundle.
- Gateway не хранит разговор и не выполняет действие.

## Последствия

Web и Telegram смогут использовать один API. Следующий совместимый контракт добавит сохранённое action и
карточку подтверждения после проектирования Conversation Service и Widget SDK. Для внешнего identity
provider отдельно выбирается безопасный способ передачи user context между сервисами.
