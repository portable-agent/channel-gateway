# Разработка

Поведение меняется маленьким TDD-пакетом:

1. добавить тест и увидеть ожидаемое падение;
2. внести минимальный код;
3. упростить имена и зависимости;
4. выполнить `pnpm lint`, `pnpm test`, `pnpm build`;
5. обновить `SERVICE.md` и документацию, если изменилась граница.

Тип `Message` и внешний ответ создаются из snapshot OpenAPI командой `pnpm generate`. Генерируемый файл
не редактируется вручную. Обновление snapshot выполняется только из подписанного release контрактов.

Отступ — четыре пробела. Tab запрещён. В тестах не используются настоящие токены или данные людей.
