# Карточка Channel Gateway

| Поле               | Значение                                                                    |
| ------------------ | --------------------------------------------------------------------------- |
| Ответственность    | Принять нормализованное сообщение любого канала и вызвать Agent Runtime     |
| Владелец           | `portable-agent/backend`                                                    |
| Язык               | TypeScript, Node.js 24                                                      |
| Входящий контракт  | `POST /api/v1/messages`, Channel Gateway API `2.2.0`                        |
| Исходящий контракт | `POST /api/v1/proposals`, Agent Runtime API `2.2.0`                         |
| Свои данные        | Нет постоянного хранилища; сервис stateless                                 |
| Прямые зависимости | OIDC JWKS и Agent Runtime                                                   |
| Не отвечает за     | API мессенджера, хранение диалога, approval, workflow и выполнение действия |
| SLO                | Не определён до сквозного baseline-теста                                    |

## Безопасные границы

- `tenantId` и `userId` не принимаются из JSON;
- входящий JWT проверяется по issuer, audience и подписи;
- доступные коннекторы приходят только из конфигурации сервиса;
- внутренний ответ Agent Runtime и токены не пишутся в обычные логи.
